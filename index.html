About

The path was identity

I am an Identity Engineer. I own Entra ID and the access plane around it — Azure, Intune, SharePoint, Atlassian, and 1Password — and I build the systems that enforce Conditional Access, PIM, and joiner / mover / leaver. The code is Python, Django, Microsoft Graph API, and Logic Apps. The point is least privilege that runs without a spreadsheet.

That is not a late career turn. The BSc in Computer Science is where identity and access control started. The MSc in Cybersecurity is where I went deep on IAM and GRC. SevenX was the first production seat: I owned access control and identity provisioning, not as coursework. Hunt&Hackett put me in the SOC. Leftover access after incidents confirmed the interest — I did not want to keep detecting identity problems. I wanted to own the systems. I moved into SecOps, where I own identity and build the IAM / IGA platforms, including a review system that cut access-review effort by 25%.

Work

Identity systems I ship

grurpID

Joiner / mover / leaver automation

production
Problem

Employee lifecycle access reviews were manual. Joiners waited, movers kept stale access, and reviewers spent hours in spreadsheets.

Built

A JML platform that manages account lifecycle and access end-to-end, using Django and Microsoft Graph API against Entra ID.

Result

Replaced manual lifecycle reviews and cut operational IAM effort by 25%.

Entra ID Django Graph API IGA

ExitScan

Leaver access and orphaned accounts

production
Problem

People left, but cloud accounts and downstream app access often stayed behind — orphaned identities that audits and attackers both find.

Built

Offboarding automation that detects orphaned cloud accounts and revokes access across downstream apps after departure.

Result

Leaver access is revoked as a process, not a hope — fewer leftover accounts after someone has already gone.

Offboarding Entra ID Cloud IAM

AuditVault

production

Built

Automation that collects ISO 27001 evidence from identity logs and turns raw access data into auditor-ready packs.
